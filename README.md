Vou te guiar em cada uma:

---

**1. Gemini (gratuita)**
- Acesse: https://aistudio.google.com/apikey
- Clique em **Create API Key**
- Copia e cola no campo do add-on

---

**2. Telegram — Bot Token**
- Abra o Telegram e procure por **@BotFather**
- Envie `/newbot`
- Escolha um nome (ex: `Monitor 3D`) e um username (ex: `monitor3d_bot`)
- Ele te devolve o token no formato `123456789:AAF...`

---

**3. Telegram — Chat ID**
- Procure por **@userinfobot** no Telegram
- Envie qualquer mensagem
- Ele responde com seu ID numérico (ex: `987654321`)

---

**4. OctoPrint API Key**
- Acesse o OctoPrint no navegador
- Clique na chave inglesa (Configurações) → **Application Keys** ou **API**
- Copie a **Global API Key**

---

**5. Token do Home Assistant** *(não precisa preencher — o add-on pega automaticamente via Supervisor)*
